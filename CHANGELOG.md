## [5.0.0] - 2026-08-02

### Added
- Interactive Recon Command Generator
- Dynamic sidebar with automatic tool loading
- 35+ supported security tools
- Live tool search
- Quick scan presets
- Command history (LocalStorage)
- Export commands as TXT

- Dark terminal-inspired UI
- Modular JavaScript architecture
