# Security Policy

## Supported Versions

The latest stable release of ReconCG receives security updates.

| Version | Supported |
|---------|-----------|
| 5.x | ✅ Yes |
| < 5.0 | ❌ No |

## Reporting a Security Issue

If you discover a security issue in ReconCG, please report it responsibly.

Please do not publicly disclose security vulnerabilities before they have been reviewed.

To report an issue:

- Open a private GitHub Security Advisory (if enabled).
- Or open a GitHub Issue for non-sensitive security improvements.
- Include clear reproduction steps, affected files, and any relevant screenshots.

## Scope

ReconCG is a client-side application that generates command-line syntax. It does not execute commands, collect user data, or communicate with external servers.

## Responsible Disclosure

We appreciate responsible disclosure and will investigate valid reports as quickly as possible.
