# Contributing to ReconCG

Thank you for your interest in contributing to ReconCG!

We welcome improvements, bug fixes, documentation updates, and new ideas.

## Ways to Contribute

- Report bugs by opening a GitHub Issue.
- Suggest new features or improvements.
- Improve documentation.
- Fix bugs and submit Pull Requests.
- Add support for additional security tools.

## Development Setup

1. Fork the repository.
2. Clone your fork.

```bash
git clone https://github.com/YOUR_USERNAME/ReconCG.git
```

3. Open the project folder.

4. Since ReconCG is a static web application, simply open `index.html` in your browser or use a local web server such as VS Code Live Server.

## Coding Guidelines

- Keep JavaScript modular.
- Use meaningful variable and function names.
- Follow the existing project style.
- Test changes before submitting.

## Pull Request Checklist

- Code has been tested.
- No syntax errors.
- Existing functionality is not broken.
- Documentation updated if required.

## Questions

If you have questions or suggestions, please open a GitHub Issue.

Thank you for helping improve ReconCG!
